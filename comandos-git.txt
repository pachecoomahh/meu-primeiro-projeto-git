Lista COMPLETA de Comandos Git Aprendidos:
git init - Inicializa um repositorio Git
git clone - Clona um repositorio remoto
git add - Adiciona arquivos a area de staging
git commit - Confirma as alteracoes no repositorio local
git status - Mostra o status dos arquivos
git branch - Lista as branches e mostra onde voce esta
git checkout -b nova-funcionalidade - Cria uma nova branch e ja muda para ela
git checkout principal - Volta para a branch principal
git push origin <nome-da-branch> - Envia a branch para o GitHub
