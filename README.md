## Reflexão Final
1. Qual a importância do Git para desenvolvimento de software?
O Git permite versionamento, trabalho em equipe e histórico seguro do código.

2. Como o uso de branches pode ajudar no trabalho em equipe?
Branches permitem trabalhar em funcionalidades diferentes sem quebrar o código principal.

3. Por que é importante escrever mensagens de commit claras?
Para facilitar o entendimento do histórico e o trabalho em equipe.

4. Quando você usaria o arquivo .gitignore?
Para ignorar arquivos sensíveis, temporários e configurações locais.

5. Como o histórico de commits do seu repositório demonstra seu aprendizado?
Mostra a evolução desde a criação do repo até o uso de branches, merges e boas práticas.
